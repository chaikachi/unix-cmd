# unix-cmd
Практическая работа 1, вариант 29 ИКБО-23-25

Общее описание

Эмулятор командной строки, приближенный к работе в командной строке UNIX-подобных систем.

Поддерживаемые команды

* ls []/[путь] - просмотр содержимого по заданному пути. Если путь не указан, то показывает содержимое текущей директории.
* cd [путь] - переход в заданную директорию. Если путь не указан, возвращает в корень.
* vfs-safe [название файла] - сохранение конфигурации виртуальной файловой системы в файл.
* rev [строка] - инверсия введённой строки.
* whoami [] / who [] - вывод информации о текущем пользователе.
* mv [откуда] [куда] - перемещение и переименовывание файла.
* cp [откуда] [куда] - копирование файла.
* exit [] - завершение работы программы.

Структура VFS

Для реализации VFS используется JSON-файл с заранее прописанными путями к файлам.
* type - dir (директория, папка) или file (файл).
* content - массив, в котором указаны вложенные папки/файлы или строка, которая содержит наполнение файла.
Файл находится в папке src.

Запуск программы

Для запуска интерактивного режима (ручного ввода команд), запустите файл run.bat.

Предусмотрено автоматическое выполнение команд с помощью скриптов. Файлы находятся в папке tests вместе с bat-файлами для их запуска.
